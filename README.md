## Overview

This repository contains practical AI coursework implementations focused on:

- Uninformed and informed search strategies
- Heuristic-based problem solving
- Genetic algorithms
- Optimization and search visualization

It combines Java and Python implementations to explore how different AI approaches solve navigation, constraint, and optimization problems.

## Repository Structure

- `Uninformed & Informed search/`
  - `Uninformed Search/` — BFS, DFS, DLS, IDS, UCS, and related visualizations
  - `Informed Search/` — A*, Greedy, RBFS, IDA*, SMA*, and heuristic-based search examples
- `Invent Different Heuristics/` — heuristic design examples and related outputs
- `Genetic Algorithm/` — Python implementations for optimization tasks such as 8-puzzle and N-Queens problems

## Included Topics

- Search algorithms
- Heuristic evaluation
- Problem state exploration
- Optimization using genetic methods
- Visual comparison of algorithm behavior

## Example Run

Python scripts can be executed directly from the project root:

```bash
python "Genetic Algorithm/queen_8.py"
python "Genetic Algorithm/puzzle_8.py"
```
